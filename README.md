# TeamFinder

Веб-платформа для разработчиков, дизайнеров и других IT-специалистов, позволяющая находить единомышленников и собирать команды для работы над pet-проектами.

## Стек технологий

- **Язык:** Java 17
- **Фреймворк:** Spring Boot 3, Spring Web, Spring Data JPA, Spring Security
- **База данных:** PostgreSQL 15
- **Шаблонизатор:** Thymeleaf
- **Контейнеризация:** Docker, Docker Compose
- **Тестирование:** JUnit 5, Mockito
- **Сборка:** Maven

## Ключевой функционал

- **Управление пользователями:** Регистрация, аутентификация, профили участников, динамическая генерация SVG-аватаров при создании аккаунта, валидация контактов и смены паролей.
- **Проекты:** Публикация pet-проектов, пагинация страниц, смена статусов проекта.
- **Командная работа:** Присоединение пользователей к проектам в качестве участников.
- **Система навыков:**
    - Асинхронное автодополнение тегов технологий при вводе.
    - Привязка стека технологий к проектам без перезагрузки страниц.
    - Фильтрация каталога проектов по конкретным технологиям.

## Архитектурные особенности

- **Трехслойная архитектура:** Четкое разделение на контроллеры, транзакционный сервисный слой и слой доступа к данным.
- **Реляционная модель:** Использование связей One-to-Many и Many-to-Many (авторство, участники, необходимые навыки проектов).
- **Оптимизация ORM:** Устранена проблема N+1 запросов при загрузке авторов проектов с помощью `@EntityGraph`.
- **Безопасность сущностей:** Корректная реализация `equals()` и `hashCode()` для Hibernate-сущностей, исключающая аномалии при работе со связями `Set` в транзакциях.
